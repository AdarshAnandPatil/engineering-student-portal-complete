# Engineering Student Portal

A student-focused engineering portal with:

- E-Library: Study Materials, Important Questions, Question Papers, Assignments, Lab Manuals, Lab Programs and Projects
- Semester-wise SGPA and CGPA calculators
- Placement preparation: Aptitude, Coding, Technical and Interview resources
- Coding practice resources
- Aptitude practice
- Resume builder
- Internship guidance
- Announcements
- Academic calendar
- Project ideas
- Useful engineering links

## Run

```bash
npm install
npm start
```

Open `http://localhost:3000`.

## Important

The included external resources are links to official/public learning platforms. Company hiring information and university results should be verified on the official source before relying on them.

This version does not include Attendance, as requested.
